description of the portogram 

This program is a simple security event logger that simulates a login system. It stores a predefined username (admin) and password (Password123!) and retrieves the computer's local IP address using the socket module. The program displays a security log heading and repeatedly asks the user to enter a username and password until the correct credentials are provided. For each login attempt, a random event ID and the current timestamp are generated. If the entered details match the stored credentials, the program logs a successful login, displays the event information, and grants access. If the credentials are incorrect, it logs a failed login attempt, displays the event details, shows an access denied message, and generates a security alert containing the IP address.
