description of the portogram 

This program is a menu-driven security tool Before using any of the three features, the user must enter the correct administrator username and password. This helps keep the tool secure and prevents unauthorised access. 
After logging in, the user can choose from three options. The first is a security event counter, which asks the user to enter passwords and then counts how many are correct or incorrect. The second is a brute-force simulator, which gives a limited number of attempts to guess a password before the account is locked. The third is a login authentication system, which checks a username and password and freezes the account after three failed attempts. The program also includes an option to exit.
